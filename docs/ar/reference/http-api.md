# مرجع HTTP API

عنوان URL الأساسي: `http://<host>:<port>/api/v1`. جميع نقاط النهاية تتطلب مصادقة bearer (`Authorization: Bearer <token>`)؛ والطلبات غير المصادَقة تحصل على 401 + تحدٍّ من نوع `Basic`. تطبيق الأدوار: طلبات الكتابة من reader تحصل على 403؛ و`/users` بغير GET للمدير فقط.

الأخطاء لها شكل موحّد `{"error": "..."}`؛ والترقيم الصفحي مضمّن (`?limit=` بين 1..=1000، و`?offset=`).

## repos — فهرس المستودعات

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/repos` | سرد الفهرس |
| POST | `/repos` | تسجيل (`name` مطلوب، وبالصيغة نفسها لأسماء وظائف المرآة) |
| GET | `/repos/{name}` | سجل واحد |
| DELETE | `/repos/{name}` | حذف (409 ما دامت وظيفة مرآة حية أو توجد PR مفتوحة) |
| GET | `/repos/{name}/prs` | قائمة PR محصورة بمستودع |
| POST/GET | `/repos/{name}/runs` | سجلات تشغيل CI (انظر [سجلات تشغيل CI](../guide/ci-runs.md)) |

## prs — طلبات السحب

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/prs?state=&base=&repo=&limit=&offset=` | قائمة عامة (`state` ∈ open/closed/merged) |
| POST | `/prs` | إنشاء (العنوان، المستودع، الأساس، الرأس، إلخ) |
| GET | `/prs/{number}` | سجل واحد |
| POST | `/prs/{number}/merge` | دمج (squash/fast-forward؛ التعارضات 409 مع قائمة تعارضات) |

الصيغة المحصورة بالمستودع: `GET /repos/{name}/prs` — المسار هو من يحدد المستودع؛ وأي مرشح `?repo=` يخالفه يعيد 400.

## users — المستخدمون والأدوار (للمدير)

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/users` | سرد (للمدير) |
| POST | `/users` | إنشاء/تحديث (الاسم نفسه = تدوير الرمز أو تغيير الدور؛ مع حفظ `created_us`) |
| GET | `/users/{name}` | سجل واحد (للمدير) |
| DELETE | `/users/{name}` | حذف (للمدير، ولا رجعة فيه) |

الأدوار: `admin` (كل شيء) / `operator` (قراءة-كتابة) / `reader` (قراءة فقط). الحقول والتحقق: انظر [الصلاحيات والمستخدمون](../guide/rbac.md).

## mirror — وظائف المرآة

| الطريقة | المسار | الوصف |
|---|---|---|
| GET | `/mirror/jobs` | سرد جميع الوظائف (بما فيه `last_status` / `last_lane` / `last_detail`) |
| POST | `/mirror/jobs` | إنشاء/تحديث (تحقق الاسم نفسه يعيد ضبط الوظيفة بالكامل) |
| DELETE | `/mirror/jobs/{name}` | حذف وظيفة |
| POST | `/mirror/run` | تشغيل يدوي (بجسم `{"job":"<name>"}`، و202 غير متزامن) |

الحقول والتحقق ودلالات القنوات: انظر [المرآة والتدفق العكسي](../guide/mirror.md).

## git-http — البروتوكول الذكي

`/git/{repo}/*`: عمليات clone/fetch (upload-pack) وpush (receive-pack). المصادقة وتفاصيل السلوك والحدود: انظر [بروتوكول git-http](../guide/git-http.md).

## الأعراف المشتركة

- `limit` افتراضه 50 وسقفه 1000 في جميع نقاط نهاية السرد (`limit=0` → 400)؛
- معاملات الترقيم الصفحي **مضمّنة** في سلسلة الاستعلام (دون كائن غلاف متداخل)؛
- الحقول التي يخصصها الخادم (مثل `number` و `started_us`) يضبطها الخادم؛ والقيم المزوّدة من العميل تُستبدَل؛
- الأخطاء لا تسرّب تفاصيل داخلية (شكل `internal server error` الثابت)؛ والتفاصيل تذهب إلى سجلات الخادم.
